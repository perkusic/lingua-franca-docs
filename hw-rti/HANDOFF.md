# Handoff — editing HW-RTI_project_specification.html

**Este arquivo não é mais a fonte.** O handoff vive no projeto
**LinguaFranca-HW-RTI**, no doc `claude/HANDOFF_hw_rti_spec.md`, e é lido
automaticamente por qualquer conversa dentro do projeto — não precisa ser colado.

Manter uma cópia completa aqui já causou divergência uma vez, então esta passou a
ser só um ponteiro.

## O que está no projeto

- `claude/HANDOFF_hw_rti_spec.md` — convenções da especificação (IDs `FR-nn`,
  `NFR-nn`, `D-n`, `OQ-n` e companhia; figuras em `viewBox="0 0 780 H"`; paleta;
  estilo) mais os **pontos vivos do desenho**: o campo `minInTransit` e a pergunta
  aberta OQ-4, a correção sobre a propagação de PTAG em §7.6, e a fronteira de
  fidelidade que o harness diferencial de §10.2 precisa respeitar.
- `claude/HANDOFF_lingua_franca_docs.md` — os documentos irmãos. A §9.9 deles é a
  ponte para esta especificação.
